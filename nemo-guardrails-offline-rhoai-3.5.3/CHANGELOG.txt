版本 1.3 — 2026-11-24

- 新增 response_language：zh-CN（默认）和 zh-TW（台湾繁体）。旧参数文件兼容。
- 固定提示使用台湾用语，如“觸發規則”“金鑰”“存取權杖”“匯出客戶明細”。
- 共享规则增加台湾繁体输入表达，保留已有简体与英文匹配和全部规则编号。
- 增加台湾繁体配置样例、速查与完整 Word/HTML 部署手册。
- 渲染时选择提示语言，服务验收同时检查语言，避免旧配置导致误判成功。
- 41 个本地测试方法；58 条正反例均在两种提示语言下检查。
- 保留 720h token 申请、实际到期记录、Playground 凭据更新及恢复步骤。
- 保留 NeMo 主模型 max_tokens=64，Playground 两个模型 Max tokens=128。

升级时复用原 settings.json，按需添加 response_language，合并自定义规则后重新 render。
已有服务按手册第 8.5 节仅更新规则 ConfigMap；不需要因语言切换重新安装。
此版本完成本地测试与文件检查；仍须在目标集群验证新规则加载与实际页面结果。

版本 1.2 — 2026-11-24

对部署手册、速查步骤和脚本做一致性核对，修正以下流程缺口：
- 新解压包缺少 settings.json 或 rendered/ 时，明确提示初始化和渲染步骤。
- token 等不应用 YAML 的操作不再要求先生成 rendered/。
- 新增 wait-playground，检查指定项目的 OGX Ready 与 Deployment 就绪。
- trust 在目标 Playground 存在并就绪之后才应用 CA；保留已有 TLS 配置。
- verify 新增 --token-file，可验证实际准备配置到端点的 token。
- 修正接口验收外层等待预算，保留安全的 HTTP 状态诊断，不回显凭据。
- 接口检查严格核对命中规则集合，并报告无效 JSON 或缺少回答。
- 手册补齐 MaaS 完整模型基址、端点/Playground 重建顺序和 macOS 校验命令。
- 保留默认申请 720h（30 天）token，以及 UTC/北京时间的实际到期记录。
- 本地测试扩展至 32 个方法，覆盖 44 条规则输入和部署/续期/恢复流程。

此版本没有修改业务拦截规则、模型 ID 样例或 NeMo 主模型 max_tokens=64。
目标 Playground 的两条模型配置仍均使用 Max tokens=128。
本地流程测试模拟集群和 HTTP 返回；目标离线集群仍须执行手册验收。

升级方式：将新包解压到新目录，核对并复用原 settings.json，重新 render。
不要覆盖原 private/；不需要因升级本包而重新 install 已存在的 NeMo 服务。
